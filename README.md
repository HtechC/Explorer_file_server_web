# Explorer_file_server_web
Explorer file server web

A web-based file explorer, but with more advanced features.
------------------------------------------------------------------------------
How to activate it:
  - Copy the downloaded "server_file_net" folder to the root of the C: drive.
  - Place the files you want to add into the explorer.
  - Run "actu.ps1" using PowerShell.
  - Run "explorer.exe".
  - Your files should appear. (Refresh the page if they do not.)
